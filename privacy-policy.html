Polaris: AI Chat Navigator

Privacy Policy

Effective date: August 28, 2026

Polaris: AI Chat Navigator is a browser extension that adds section navigation markers to supported AI chat websites. This Privacy Policy explains what information the extension accesses, how that information is used, and whether it is stored or shared.

1. Information We Process

Website Content

Polaris: AI Chat Navigator accesses the text and document structure of AI-generated responses displayed on supported websites. For ChatGPT, it also reads the current conversation's active message branch in the browser to keep long-conversation user groups complete. This access is necessary to identify headings and list structures, generate navigation markers, scroll to selected sections, and show AI response content in the full-screen text-selection feature.

Website content is processed locally within the user's browser. It is not transmitted to the developer or to any third-party server. The extension is not designed to access passwords, authentication credentials, cookies, financial information, health information, or other account information.

Extension Settings

Polaris: AI Chat Navigator stores user preferences such as top and right spacing, the maximum number of visible markers, tooltip width, enabled heading levels, and unordered-list marker preferences.

These settings are stored using the Chrome Storage Sync API. If browser synchronization is enabled, the settings may be synchronized across the user's signed-in Chrome browsers by Google under Google's applicable privacy terms. The developer cannot access these synchronized settings.

Diagnostic Logs

If the user explicitly selects a diagnostic action in About & Settings, Polaris: AI Chat Navigator records a bounded session-only log for the current tab. The log contains the extension version, coarse platform and browser summaries, viewport measurements, pointer-drag lifecycle outcomes, route and render counts, and error type names. It is designed to exclude AI response text, marker titles, full URLs, account information, prompts, cookies, tokens, error messages, and stack traces.

The log is stored only in the current tab's session storage until the tab is closed or the session is cleared. "Download only" saves a redacted JSON file locally. "Send diagnostic log" also opens a pre-addressed email draft to jefferyho.build@gmail.com; the browser does not automatically attach the local file, so the user chooses whether to attach and send it. Polaris: AI Chat Navigator does not upload diagnostic logs or add a background upload service.

Clipboard

When the user explicitly selects text and activates the copy function, Polaris: AI Chat Navigator writes the selected text to the system clipboard. The extension does not read existing clipboard content and does not transmit copied text anywhere.

2. How We Use Information

Information accessed by Polaris: AI Chat Navigator is used solely to provide its user-facing features, including section detection, navigation markers, click-to-scroll navigation, display customization, and full-screen text selection.

The extension does not use information for:

  • Advertising or personalized advertising;
  • Analytics or behavioral tracking within the extension;
  • User profiling;
  • Creditworthiness or lending decisions;
  • Selling or licensing user data; or
  • Unrelated product research.

3. Data Sharing and Disclosure

Polaris: AI Chat Navigator does not sell, rent, trade, or share website content or personal information with the developer, advertisers, data brokers, or other third parties.

The only external processing performed by the extension is the optional synchronization of non-personal extension settings through Chrome Storage Sync and the user's explicit choice to open a local diagnostic file or an email draft. The settings synchronization service is provided and controlled by Google. The extension does not include third-party analytics, telemetry, or advertising services, and it does not automatically transmit diagnostic logs.

Polaris also links to a separate support webpage. That webpage loads Google Analytics only after the visitor explicitly allows analytics. It measures only a support-page arrival from Polaris and a video-loading play-button click; it does not receive AI conversation content, extension settings, or PayPal payment details. The support page provides its own privacy information and a way to change the analytics choice.

4. Data Retention

Polaris: AI Chat Navigator does not create a persistent copy of AI responses, user prompts, or Maker navigation history. Makers are generated from the response elements currently mounted on the page.

Extension settings remain in Chrome storage until they are reset or removed by the user through the browser or extension settings. Synced settings may also be managed through the user's Google Chrome synchronization settings.

Diagnostic events remain in session storage for the current tab, are bounded in count and size, and are cleared when the tab session ends or when the browser clears session storage. A downloaded copy remains under the user's control, and any email retention is governed by the user's mail provider and choices.

5. Browser Permissions

  • Storage permission: used to save and synchronize extension preferences.
  • Host permissions: used to run the extension on supported AI chat websites and locally inspect AI response content required for navigation features.

The extension requests only the permissions needed to provide its disclosed functionality.

6. Data Security

Because website content is processed locally and is not transmitted to the developer, Polaris: AI Chat Navigator does not maintain external databases containing user content. Any synchronization of extension settings is handled through Chrome's Storage Sync service and its associated security mechanisms.

7. Chrome Web Store Limited Use Compliance

Polaris: AI Chat Navigator's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information accessed by the extension is used only to provide or improve its disclosed single purpose. It is not used or transferred for personalized advertising, profiling, data brokerage, creditworthiness decisions, or any unrelated purpose.

No human is permitted to read user website content through Polaris: AI Chat Navigator because that content is never transmitted to or stored by the developer.

8. User Choices

Users may stop all processing by disabling or uninstalling Polaris: AI Chat Navigator. Users may reset extension preferences from the extension's settings interface, clear the current tab's diagnostic session by closing the tab or clearing session storage, and may manage synchronized data through their Chrome synchronization settings. Diagnostic export is optional and user initiated.

9. Changes to This Privacy Policy

This Privacy Policy may be updated if the extension's functionality or data-handling practices change. Any material change to the types of information processed or how information is used will be disclosed through an updated Privacy Policy and, where required, through the extension interface or Chrome Web Store listing before the new practices take effect.

10. Contact

For privacy questions or requests, contact the developer through Polaris: AI Chat Navigator GitHub Issues.
