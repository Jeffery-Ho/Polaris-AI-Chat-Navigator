Polaris: AI Chat Navigator

Privacy Policy

Effective date: October 30, 2026 · Last updated: November 11, 2026

Polaris: AI Chat Navigator is a browser extension that adds section navigation markers to supported AI chat websites. This Privacy Policy explains what information the extension accesses, how that information is used, and whether it is stored or shared.

1. Information We Process

Website Content

Polaris: AI Chat Navigator accesses the text and document structure of AI-generated responses displayed on supported websites. It reads only the messages the website has already loaded into the page. "Follow the page" removes messages from its index when the website unmounts them. The optional "Long conversation mode" setting retains already loaded messages in the current page's memory for navigation, search and export. If the user explicitly turns on automatic backfill, Polaris renders messages of the user's own open conversation that the website has already delivered to the browser, using only the website's own page mechanics (scrolling its message list or pressing its own "load earlier" control) while the list is covered, then restores the reader's position. Shared conversations are never backfilled, and backfill pauses while the page is hidden. It does not call website APIs, read account tokens, or intercept or modify website requests. The index is cleared on conversation changes, page refresh, closure or returning to "Follow the page". Hidden reasoning, tool messages, alternate branches, and downloaded attachments are not indexed. This access is necessary to identify headings and list structures, generate navigation markers, scroll to selected sections, and show AI response content in the full-screen text-selection feature, and support user-initiated conversation copying and file export.

Website content is processed locally within the user's browser. It is not transmitted to the developer or to any third-party server. Polaris does not request or use your account session, authentication tokens, or credentials, and it does not call any private or undocumented website interface or access React/webpack internal state. Polaris does not ask for passwords. On extension startup, the old extension-owned conversation cache database is deleted without reading its contents. Website storage is not changed.

Extension Settings

Polaris: AI Chat Navigator stores user preferences such as top and right spacing, the maximum number of visible markers, tooltip width, enabled heading levels, and unordered-list marker preferences. No conversation content or reading mode is stored in these settings.

These settings are stored using the Chrome Storage Sync API. If browser synchronization is enabled, the settings may be synchronized across the user's signed-in Chrome browsers by Google under Google's applicable privacy terms. The developer cannot access these synchronized settings.

Trials, Purchases and Licenses

Polaris can contact its license service to initialize a seven-day trial, obtain available plans and validate an existing license. It generates a random installation identifier and independent credential; these, device activation credentials and pending purchase claims are stored in Chrome Storage Local and are not synchronized. Free platform choices stay on the device. No Polaris account or hardware fingerprint is required.

When you choose to purchase, Stripe-hosted Checkout processes payment and collects your checkout email. Card information is not stored by the extension or license service. The Cloudflare Worker and D1 service store the order, license and activation records needed for fulfillment and validation. License and activation verifiers are hashed; email and license delivery material are encrypted separately for delivery and recovery. Configured transactional email delivery uses Resend. Neither payment nor licensing includes AI conversations, prompts, browsing history, full browsing URLs or hardware fingerprints.

A recovery request uses the checkout email and returns the same confirmation whether or not a matching purchase exists. The service uses short-lived hashed-IP counters and delivery throttling to limit abuse. The test integration is separate from a production billing rollout, and local UI previews do not charge a payment method.

Diagnostic Logs

If the user explicitly selects a diagnostic action in About & Settings, Polaris: AI Chat Navigator records a bounded session-only log for the current tab. The log contains the extension version, coarse platform and browser summaries, viewport measurements, pointer-drag lifecycle outcomes, route and render counts, and error type names. It is designed to exclude AI response text, marker titles, full URLs, account information, prompts, cookies, tokens, error messages, and stack traces. Conversation history is never loaded for diagnostics.

The log is stored only in the current tab's session storage until the tab is closed or the session is cleared. "Download only" saves a redacted JSON file locally. "Send diagnostic log" also opens a pre-addressed email draft to jefferyho.build@gmail.com; the browser does not automatically attach the local file, so the user chooses whether to attach and send it. Polaris: AI Chat Navigator does not upload diagnostic logs or add a background upload service.

Clipboard

When the user activates a copy action, Polaris: AI Chat Navigator writes the selected text, a chapter, or conversation text to the system clipboard. Conversation copying includes the user messages and AI replies that have been read from the page and is independent of chapter filters or folding. When the whole conversation has finished loading, copying includes the whole conversation; otherwise it includes only the content already read from the page. The extension does not read existing clipboard content or upload copied text. Clipboard contents are managed by the user's operating system and any clipboard tools the user has enabled.

Conversation File Export

After copying a conversation, the user can explicitly save the same message scope as Markdown or HTML. Files are generated locally in the browser and downloaded to a location managed by the user; conversation text is not sent to a processing server. Exported images are represented by text labels, and raw message HTML is sanitized or escaped. Normal links remain clickable; following them contacts their destination. Downloaded files remain until the user deletes them. Any sharing or cloud backup of these files is controlled by the user and the applications or services they choose.

2. How We Use Information

Information accessed by Polaris: AI Chat Navigator is used solely to provide its user-facing features, including section detection, navigation markers, click-to-scroll navigation, display customization, conversation indexing and search, full-screen text selection, chapter or conversation copying, and local Markdown or HTML file export.

The extension does not use information for:

  • Advertising or personalized advertising;
  • Analytics or behavioral tracking within the extension;
  • User profiling;
  • Creditworthiness or lending decisions;
  • Selling or licensing user data; or
  • Unrelated product research.

3. Data Sharing and Disclosure

Polaris: AI Chat Navigator does not sell, rent or trade personal information. AI website content is not shared with the developer, advertisers, data brokers or other third parties. Payment and license information is processed only by the services described above to provide the requested purchase, authorization, delivery and recovery features.

External processing includes license-service requests, user-initiated Stripe Checkout and license email delivery, optional synchronization of extension settings through Chrome Storage Sync, and the user's explicit choice to open a diagnostic file or email draft. The settings synchronization service is provided and controlled by Google. The extension does not include third-party analytics, telemetry, or advertising services, and it does not automatically transmit diagnostic logs.

Polaris also links to a separate support webpage. That webpage loads Google Analytics only after the visitor explicitly allows analytics. It measures only a support-page arrival from Polaris and a video-loading play-button click; it does not receive AI conversation content, extension settings, or PayPal payment details. The support page provides its own privacy information and a way to change the analytics choice.

4. Data Retention

Polaris does not persist AI responses or user prompts. The conversation index and any retained loaded messages live only in the current page's memory and are cleared on conversation changes, page refresh or closure. No conversation content is written to local storage, IndexedDB, or synchronization.

Extension settings remain in Chrome storage until they are reset or removed by the user through the browser or extension settings. Synced settings may also be managed through the user's Google Chrome synchronization settings.

Diagnostic events remain in session storage for the current tab, are bounded in count and size, and are cleared when the tab session ends or when the browser clears session storage. A downloaded copy remains under the user's control, and any email retention is governed by the user's mail provider and choices.

Local installation and activation credentials remain until the extension is removed or its local storage is cleared. Device deactivation revokes its activation credential but retains the installation identity and trial deadline. Test license delivery ciphertext and order records remain for the lifetime of that test license; delivery retry metadata does not contain plaintext credentials. Short-lived rate-limit counters are periodically deleted. Contact the developer about deleting server-side test purchase and license records.

5. Browser Permissions

  • Storage permission: used to save and synchronize extension preferences. No conversation content is stored locally or synchronized.
  • Host permissions: used to run the extension on supported AI chat websites, locally inspect AI response content for navigation, and contact the disclosed license-service host for trial and license operations.

The extension requests only the permissions needed to provide its disclosed functionality.

6. Data Security

Because website content is processed locally and is not transmitted to the developer, Polaris: AI Chat Navigator does not maintain external databases containing user content. Any synchronization of extension settings is handled through Chrome's Storage Sync service and its associated security mechanisms.

7. Chrome Web Store Limited Use Compliance

Polaris: AI Chat Navigator's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information accessed by the extension is used only to provide or improve its disclosed single purpose. It is not used or transferred for personalized advertising, profiling, data brokerage, creditworthiness decisions, or any unrelated purpose.

No human is permitted to read user website content through Polaris: AI Chat Navigator because that content is never transmitted to or stored by the developer.

8. User Choices

Users may stop all processing by disabling or uninstalling Polaris: AI Chat Navigator. Users may reset extension preferences from the extension's settings interface, clear the current tab's diagnostic session by closing the tab or clearing session storage, and may manage synchronized data through their Chrome synchronization settings. Diagnostic export is optional and user initiated.
